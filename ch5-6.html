Chapter 5 · Eigenvalues

5.1Eigenvectors and eigenvalues

Which arrows does a matrix only stretch, without turning?

Multiplying a matrix by a vector gives a new vector. Think of it as the matrix moving an arrow. Here is the matrix we'll use throughout:

$$A=\begin{bmatrix}2&1\\1&2\end{bmatrix}$$

Try three arrows:

$$A\begin{bmatrix}1\\0\end{bmatrix}=\begin{bmatrix}2\\1\end{bmatrix}$$ $$A\begin{bmatrix}1\\1\end{bmatrix}=\begin{bmatrix}3\\3\end{bmatrix}$$ $$A\begin{bmatrix}1\\-1\end{bmatrix}=\begin{bmatrix}1\\-1\end{bmatrix}$$

The red arrow changed direction. The blue and orange arrows stayed on their own lines.

Those two special arrows have names. $(1,1)$ is an eigenvector with eigenvalue 3, because $A$ multiplied it by 3. $(1,-1)$ is an eigenvector with eigenvalue 1, because $A$ multiplied it by 1.

The definition, in symbols and words

$$A\mathbf x=\lambda\mathbf x,\qquad \mathbf x\neq\mathbf 0$$

"Doing $A$ to the arrow $\mathbf x$ is the same as multiplying it by the plain number $\lambda$." $\lambda$ (lambda) is just the stretch factor. It can be negative (flips the arrow) or 0 (crushes it). The zero vector never counts as an eigenvector.

Problem type: is this an eigenvector?

Multiply and look. If $A\mathbf v$ is a multiple of $\mathbf v$, yes, and the multiple is $\lambda$.

Problem type: given $\lambda$, find the eigenvectors

Move everything in $A\mathbf x=\lambda\mathbf x$ to one side: $(A-\lambda I)\mathbf x=\mathbf 0$. ($I$ is there because you can't subtract a number from a matrix. $A-\lambda I$ means "subtract $\lambda$ from each diagonal entry.") That is a null space problem from Chapter 4. For $\lambda=3$:

$$A-3I=\begin{bmatrix}-1&1\\1&-1\end{bmatrix}\sim\begin{bmatrix}1&-1\\0&0\end{bmatrix}$$

So $x_1=x_2$, which means every solution looks like this:

$$\mathbf x=x_2\begin{bmatrix}1\\1\end{bmatrix}$$

All those multiples of $(1,1)$ together are the eigenspace of $\lambda=3$. Stretching an eigenvector still gives an eigenvector, so there's always a whole line (or plane) of them, and you report a basis.

Quick facts: a triangular matrix's eigenvalues are its diagonal entries. If 0 is an eigenvalue, $A\mathbf x=\mathbf 0$ has a nonzero solution, so $A$ is not invertible.

Try it: is $(1,1)$ an eigenvector of $\left[\begin{smallmatrix}4&1\\2&3\end{smallmatrix}\right]$?

Multiply: $(4+1,\ 2+3)=(5,5)=5(1,1)$. Yes, with eigenvalue 5.

5.2Finding the eigenvalues

How do you find $\lambda$ when nobody gives it to you?

We need a nonzero solution to $(A-\lambda I)\mathbf x=\mathbf 0$. A square matrix has a nonzero null vector exactly when it isn't invertible, and that's exactly when its determinant is 0. So:

The characteristic equation

$$\det(A-\lambda I)=0$$

Its solutions are the eigenvalues. That's the reason determinants show up here.

For our matrix, subtract $\lambda$ from the diagonal and take the determinant:

$$\begin{aligned}\det\begin{bmatrix}2-\lambda&1\\1&2-\lambda\end{bmatrix}&=(2-\lambda)^2-1\\&=\lambda^2-4\lambda+3\\&=(\lambda-3)(\lambda-1)\end{aligned}$$

So $\lambda=3$ and $\lambda=1$, the same two we saw. Then find each eigenvector as in 5.1.

2×2 shortcut: the equation is always $\lambda^2-(\text{trace})\lambda+\det A=0$. The trace is the sum of the diagonal. Here: trace 4, det 3.

Algebraic multiplicity is how many times a root repeats. In $(\lambda-3)^2(\lambda-1)$, the root 3 has multiplicity 2.

Similar matrices: $A$ and $B$ are similar if $A=PBP^{-1}$. They describe the same action written in different coordinates, so they have the same eigenvalues (Theorem 4). The reverse fails: same eigenvalues doesn't guarantee similar.

Try it: eigenvalues and eigenvectors of $\left[\begin{smallmatrix}4&1\\2&3\end{smallmatrix}\right]$

Trace 7, det 10: $\lambda^2-7\lambda+10=(\lambda-5)(\lambda-2)$. For $\lambda=5$: $(1,1)$. For $\lambda=2$: $A-2I=\left[\begin{smallmatrix}2&1\\2&1\end{smallmatrix}\right]$, so $2x_1+x_2=0$, giving $(1,-2)$.

5.3Diagonalization

Why do we care? Because eigenvectors make huge powers easy.

Suppose you need $A^{10}$ times $(5,1)$. Multiplying ten times is painful. Instead, write $(5,1)$ using the eigenvectors:

$$\begin{bmatrix}5\\1\end{bmatrix}=3\begin{bmatrix}1\\1\end{bmatrix}+2\begin{bmatrix}1\\-1\end{bmatrix}$$

Each time $A$ acts, the first piece is multiplied by 3 and the second by 1. They don't interfere. So after ten rounds:

$$\begin{aligned}A^{10}\begin{bmatrix}5\\1\end{bmatrix}&=3\cdot3^{10}\begin{bmatrix}1\\1\end{bmatrix}+2\cdot1^{10}\begin{bmatrix}1\\-1\end{bmatrix}\\&=\begin{bmatrix}177149\\177145\end{bmatrix}\end{aligned}$$

Diagonalizing packages that trick into one formula:

$A=PDP^{-1}$

$P$ has the eigenvectors as columns. $D$ is diagonal, with the eigenvalues in the same order.

$$\underbrace{\begin{bmatrix}2&1\\1&2\end{bmatrix}}_{A}=\underbrace{\begin{bmatrix}1&1\\1&-1\end{bmatrix}}_{P}\underbrace{\begin{bmatrix}3&0\\0&1\end{bmatrix}}_{D}\underbrace{\tfrac12\begin{bmatrix}1&1\\1&-1\end{bmatrix}}_{P^{-1}}$$

Read it right to left: $P^{-1}$ translates into eigenvector language, $D$ does the stretching, $P$ translates back. It's like translating a sentence into a language where the math is easy, doing it, and translating back.

Powers are now simple, because the middle $P^{-1}P$ pairs cancel: $A^k=PD^kP^{-1}$, and $D^k$ just raises each diagonal entry to the $k$. (Check: $k=2$ gives $\left[\begin{smallmatrix}5&4\\4&5\end{smallmatrix}\right]$, which equals $A^2$.)

Problem type: diagonalize $A$

1.
Find the eigenvalues.
2.
Find a basis for each eigenspace.
3.
Count the vectors. An $n\times n$ matrix needs $n$ of them. If you have fewer, stop: it's not diagonalizable.
4.
Put them in $P$, and the matching eigenvalues in $D$. Check $AP=PD$, which avoids computing $P^{-1}$.

When does it fail?

When there aren't enough eigenvectors. $\left[\begin{smallmatrix}1&1\\0&1\end{smallmatrix}\right]$ has $\lambda=1$ twice, but $A-I=\left[\begin{smallmatrix}0&1\\0&0\end{smallmatrix}\right]$ forces $x_2=0$, so its only eigenvectors are multiples of $(1,0)$. One direction isn't enough for a 2×2.

Theorems in one line: diagonalizable ⇔ $n$ independent eigenvectors (Thm 5). $n$ different eigenvalues guarantees it (Thm 6). With repeats, each eigenspace's dimension must equal its multiplicity (Thm 7).

Don't mix these up

Invertible and diagonalizable are unrelated. Invertible asks "is 0 an eigenvalue?" Diagonalizable asks "are there enough eigenvectors?"

Try it: diagonalize $\left[\begin{smallmatrix}4&1\\2&3\end{smallmatrix}\right]$

From 5.2's exercise: $P=\left[\begin{smallmatrix}1&1\\1&-2\end{smallmatrix}\right]$, $D=\left[\begin{smallmatrix}5&0\\0&2\end{smallmatrix}\right]$. Two different eigenvalues, so it works.

5.4Matrices of linear transformations

The same action can have different matrices, depending on the coordinates you use.

A linear transformation $T$ is the action itself. A matrix is how you write it down after choosing a basis, the way one sentence can be written in English or Spanish.

The one rule

Column $j$ of the matrix is: what $T$ does to basis vector $j$, written in that basis.

Example with polynomials. Let $T(\mathbf p)=\mathbf p'$ (the derivative) on polynomials of degree ≤2, with basis $\{1,t,t^2\}$. Coefficient lists are in the order (constant, $t$, $t^2$):

1.
$T(1)=0$, which is $(0,0,0)$.
2.
$T(t)=1$, which is $(1,0,0)$.
3.
$T(t^2)=2t$, which is $(0,2,0)$.
$$[T]_{\mathcal B}=\begin{bmatrix}0&1&0\\0&0&2\\0&0&0\end{bmatrix}$$

Example with our matrix. Use the eigenvectors as the basis: $\mathbf b_1=(1,1)$, $\mathbf b_2=(1,-1)$. Then $T(\mathbf b_1)=3\mathbf b_1$ and $T(\mathbf b_2)=1\mathbf b_2$, so the columns are $(3,0)$ and $(0,1)$:

$$[T]_{\mathcal B}=\begin{bmatrix}3&0\\0&1\end{bmatrix}=D$$

That's what diagonalization means: in the eigenvector basis, the action is pure stretching (Theorem 8).

Formula for any basis in $\mathbb R^n$: $[T]_{\mathcal B}=P^{-1}AP$, where $P$'s columns are the basis vectors.

Try it: $T(\mathbf p)=\mathbf p+\mathbf p'$ on $\{1,t\}$

$T(1)=1$ gives $(1,0)$. $T(t)=t+1$ gives $(1,1)$. Matrix: $\left[\begin{smallmatrix}1&1\\0&1\end{smallmatrix}\right]$.

5.5Complex eigenvalues

What if a matrix turns every arrow, so that no arrow stays on its line?

Take a 90° rotation, $\left[\begin{smallmatrix}0&-1\\1&0\end{smallmatrix}\right]$. Every arrow turns, so no real eigenvector can exist. The algebra agrees: $\lambda^2+1=0$ has no real solutions, only $\lambda=\pm i$, where $i^2=-1$.

What a complex eigenvalue means

Complex eigenvalues signal rotation. For a real matrix they come in pairs $a\pm bi$. The pair tells you the rotation angle and the stretch.

The cleanest case is a matrix of this shape:

$$C=\begin{bmatrix}a&-b\\b&a\end{bmatrix}$$

Its eigenvalues are $a\pm bi$. Two numbers describe it: the stretch $r=\sqrt{a^2+b^2}$, and the angle $\varphi$ of the point $(a,b)$.

Multiplying by $C$ rotates by $\varphi$ and scales by $r$. Example: $\left[\begin{smallmatrix}1&-1\\1&1\end{smallmatrix}\right]$ has $a=1,b=1$, so $r=\sqrt2$ and $\varphi=45^\circ$. Check: it sends $(1,0)$ to $(1,1)$, which is turned $45^\circ$ and has length $\sqrt2$.

Problem type: find $P$ and $C$ with $A=PCP^{-1}$

Most matrices aren't in that neat shape, but they're the same thing in other coordinates (Theorem 9). Take $A=\left[\begin{smallmatrix}1&-2\\1&3\end{smallmatrix}\right]$:

1.
Trace 4, det 5: $\lambda^2-4\lambda+5=0$. The quadratic formula gives $\lambda=2\pm i$.
2.
Choose the one with the minus sign: $\lambda=2-i$, so $a=2$, $b=1$.
3.
Write $A-\lambda I$ and use one row. Row 2 is $[\,1\ \ \ 1+i\,]$, so $x_1+(1+i)x_2=0$. Taking $x_2=1$: $\mathbf v=(-1-i,\ 1)$.
4.
Split $\mathbf v$ into real and imaginary parts: $\mathbf v=(-1,1)+i(-1,0)$. Those are the columns of $P$: $P=\left[\begin{smallmatrix}-1&-1\\1&0\end{smallmatrix}\right]$.
5.
$C=\left[\begin{smallmatrix}a&-b\\b&a\end{smallmatrix}\right]=\left[\begin{smallmatrix}2&-1\\1&2\end{smallmatrix}\right]$. Check: $AP=PC$.

Long-run behavior: $r<1$ spirals in, $r=1$ goes around an ellipse, $r>1$ spirals out.

Try it: eigenvalues, $r$ and $\varphi$ for $\left[\begin{smallmatrix}3&-4\\4&3\end{smallmatrix}\right]$

$a=3,b=4$: $\lambda=3\pm4i$, $r=5$, $\varphi\approx53^\circ$ (the angle of the point $(3,4)$).

Chapter 6 · Orthogonality

6.1Dot product, length, right angles

One operation gives you length, distance and right angles in any dimension.

The dot product multiplies matching entries and adds, producing one number:

$$(1,2,2)\cdot(2,-1,0)=2-2+0=0$$

It measures how much two arrows point the same way: positive means similar direction, negative means opposite-ish, and 0 means a right angle. "Orthogonal" is the math word for perpendicular.

  • Length: $\|\mathbf v\|=\sqrt{\mathbf v\cdot\mathbf v}$. For $(3,4)$: $\sqrt{9+16}=5$. It's just the Pythagorean theorem.
  • Unit vector (length 1, same direction): divide by the length. $(3,4)\to(3/5,4/5)$.
  • Distance between two points: subtract them, then take the length.

Notice that our eigenvectors are orthogonal: $(1,1)\cdot(1,-1)=0$. We'll use that pair below.

$W^\perp$, "W perp"

If $W$ is a subspace, $W^\perp$ is everything perpendicular to all of $W$. If $W$ is the floor, $W^\perp$ is the vertical line through the origin. Their dimensions add up to $n$.

To find it: $\mathbf z$ must have dot product 0 with each spanning vector of $W$. Put those vectors in as the rows of a matrix and find the null space. Example: for $W=\operatorname{Span}\{(1,0,1),(0,1,1)\}$, the equations $z_1+z_3=0$ and $z_2+z_3=0$ give $W^\perp=\operatorname{Span}\{(-1,-1,1)\}$.

Why Theorem 3 is true: $A\mathbf x=\mathbf 0$ says each row of $A$ dotted with $\mathbf x$ is 0. So $\operatorname{Nul}A$ is exactly what's perpendicular to the rows: $(\operatorname{Row}A)^\perp=\operatorname{Nul}A$. Applying this to $A^T$ gives $(\operatorname{Col}A)^\perp=\operatorname{Nul}A^T$.

Try it: length and unit vector of $(1,2,2)$

Length $\sqrt{1+4+4}=3$. Unit vector: $(1/3,\ 2/3,\ 2/3)$.

6.2Orthogonal sets and shadows

When your basis vectors are perpendicular, you can find weights without row reducing.

Write $\mathbf y=(3,1)$ using $\mathbf u_1=(1,1)$ and $\mathbf u_2=(1,-1)$. Because they're perpendicular, each weight comes from a quick formula:

$$c=\frac{\mathbf y\cdot\mathbf u}{\mathbf u\cdot\mathbf u}$$ $$c_1=\frac{4}{2}=2,\qquad c_2=\frac{2}{2}=1$$

Check: $2(1,1)+1(1,-1)=(3,1)$. Dotting with $\mathbf u_1$ makes the $\mathbf u_2$ part vanish, since it's perpendicular. That's why each weight can be found on its own.

Projection: the shadow of an arrow on a line

Shine a light perpendicular to the line. The shadow of y lands at ŷ, and the leftover z meets the line at a right angle.

Projection onto the line through $\mathbf u$

$$\hat{\mathbf y}=\frac{\mathbf y\cdot\mathbf u}{\mathbf u\cdot\mathbf u}\,\mathbf u,\qquad \mathbf z=\mathbf y-\hat{\mathbf y}$$

Then $\mathbf y=\hat{\mathbf y}+\mathbf z$: "the part along $\mathbf u$" plus "the part perpendicular to $\mathbf u$." The distance from $\mathbf y$ to the line is $\|\mathbf z\|$.

Here: $\hat{\mathbf y}=\tfrac42(1,1)=(2,2)$ and $\mathbf z=(3,1)-(2,2)=(1,-1)$. Check: $(1,-1)\cdot(1,1)=0$.

Orthonormal columns

Orthonormal means perpendicular and each of length 1. If a matrix $U$ has orthonormal columns, then $U^TU=I$, because the entries of $U^TU$ are the dot products of the columns: 1 on the diagonal, 0 elsewhere. Multiplying by $U$ also keeps lengths and angles the same: $\|U\mathbf x\|=\|\mathbf x\|$.

A square matrix like this is called an orthogonal matrix, and then $U^{-1}=U^T$, so you get the inverse for free.

Try it: project $(4,2)$ onto the line through $(1,1)$

$\frac{4+2}{2}=3$, so $\hat{\mathbf y}=(3,3)$ and $\mathbf z=(1,-1)$. Check: $(1,-1)\cdot(1,1)=0$.

6.3Projecting onto a plane

What's the closest point on a plane to a point off the plane?

Picture a pole's tip above the floor. The closest floor point is straight below it. That point is the projection, $\hat{\mathbf y}=\operatorname{proj}_W\mathbf y$.

To compute it: take a shadow on each vector of an orthogonal basis of $W$, and add the shadows up.

$$\hat{\mathbf y}=\frac{\mathbf y\cdot\mathbf u_1}{\mathbf u_1\cdot\mathbf u_1}\mathbf u_1+\frac{\mathbf y\cdot\mathbf u_2}{\mathbf u_2\cdot\mathbf u_2}\mathbf u_2$$

Example. $\mathbf y=(1,2,3)$, and $W$ is the floor, with $\mathbf u_1=(1,1,0)$, $\mathbf u_2=(1,-1,0)$.

1.
Check they're perpendicular: $\mathbf u_1\cdot\mathbf u_2=0$.
2.
Weights: $\tfrac32$ and $-\tfrac12$.
3.
$\hat{\mathbf y}=\tfrac32(1,1,0)-\tfrac12(1,-1,0)=(1,2,0)$. That's the closest point. It makes sense: the point directly below $(1,2,3)$.
4.
Leftover: $\mathbf z=\mathbf y-\hat{\mathbf y}=(0,0,3)$. Distance from $\mathbf y$ to $W$: $\|\mathbf z\|=3$.

The three theorems, in words

Thm 8: every $\mathbf y$ splits in exactly one way into (a piece in $W$) + (a piece perpendicular to $W$).

Thm 9: the piece in $W$ is the closest point of $W$ to $\mathbf y$.

Thm 10: if the basis is orthonormal, the formula shortens to $\hat{\mathbf y}=UU^T\mathbf y$.

The most common mistake

The formula only works if the basis is orthogonal. Check the dot products first. If they aren't 0, use Gram–Schmidt (next section) before projecting.

Try it: $\mathbf y=(3,4,5)$, $\mathbf u_1=(1,0,1)$, $\mathbf u_2=(1,0,-1)$

The dot product of the $\mathbf u$'s is 0. Weights: $\tfrac82=4$ and $\tfrac{-2}{2}=-1$. $\hat{\mathbf y}=4\mathbf u_1-\mathbf u_2=(3,0,5)$. $\mathbf z=(0,4,0)$. Distance 4.

6.4Gram–Schmidt and QR

The last two sections need perpendicular vectors. What if yours aren't?

Gram–Schmidt straightens them. Keep the first vector. From each later vector, subtract its shadow on the vectors you've already kept. By section 6.2, what's left is perpendicular to them.

Example. $\mathbf x_1=(1,1,0)$, $\mathbf x_2=(1,0,1)$ (their dot product is 1, so they aren't perpendicular).

1.
Keep the first: $\mathbf v_1=(1,1,0)$.
2.
Shadow of $\mathbf x_2$ on $\mathbf v_1$: $\tfrac{\mathbf x_2\cdot\mathbf v_1}{\mathbf v_1\cdot\mathbf v_1}\mathbf v_1=\tfrac12(1,1,0)$.
3.
Subtract: $\mathbf v_2=(1,0,1)-(\tfrac12,\tfrac12,0)=(\tfrac12,-\tfrac12,1)$. Multiply by 2 to clear fractions: $(1,-1,2)$.
4.
Check: $(1,1,0)\cdot(1,-1,2)=0$.

A third vector works the same way: subtract its shadows on $\mathbf v_1$ and $\mathbf v_2$. Always use the new $\mathbf v$'s, not the original $\mathbf x$'s.

QR: a record of what Gram–Schmidt did

$A=QR$ splits a matrix into two parts. $Q$ has the straightened vectors, scaled to length 1. $R$ is upper triangular and holds the recipe for rebuilding the original columns from them.

1.
Run Gram–Schmidt on the columns of $A$.
2.
Divide each result by its length. These are the columns of $Q$.
3.
Compute $R=Q^TA$. (It works because $Q^TQ=I$.)

With the columns above, $A=\left[\begin{smallmatrix}1&1\\1&0\\0&1\end{smallmatrix}\right]$:

$$Q=\begin{bmatrix}1/\sqrt2&1/\sqrt6\\1/\sqrt2&-1/\sqrt6\\0&2/\sqrt6\end{bmatrix}$$ $$R=\begin{bmatrix}\sqrt2&1/\sqrt2\\0&\sqrt6/2\end{bmatrix}$$
Try it: straighten $\mathbf x_1=(1,0,1)$, $\mathbf x_2=(1,1,0)$

Shadow: $\tfrac12(1,0,1)$. $\mathbf v_2=(\tfrac12,1,-\tfrac12)$, which scales to $(1,2,-1)$. Check: $(1,0,1)\cdot(1,2,-1)=0$.

6.5Least squares

When $A\mathbf x=\mathbf b$ has no solution, what's the best you can do?

The simplest possible case. You measure one number twice and get 1 and 3. That's the system $x=1$, $x=3$, which has no solution. The sensible compromise is the average, 2. Least squares finds that compromise automatically.

In general: $A\mathbf x$ can only reach vectors in $\operatorname{Col}A$. If $\mathbf b$ isn't in there, aim for the closest point that is, $\hat{\mathbf b}$. That's the projection from 6.3. A least-squares solution $\hat{\mathbf x}$ is whatever gets you there: $A\hat{\mathbf x}=\hat{\mathbf b}$.

The normal equations

$$A^TA\,\hat{\mathbf x}=A^T\mathbf b$$

Where this comes from: the leftover $\mathbf b-A\hat{\mathbf x}$ must be perpendicular to every column of $A$. That says $A^T(\mathbf b-A\hat{\mathbf x})=\mathbf 0$. Rearranging gives the equation above.

Test it on the measurements: $A=\left[\begin{smallmatrix}1\\1\end{smallmatrix}\right]$, $\mathbf b=(1,3)$. Then $A^TA=2$ and $A^T\mathbf b=4$, so $2\hat x=4$ and $\hat x=2$. The average, as promised.

Problem type: find the least-squares solution

$A=\left[\begin{smallmatrix}1&1\\1&0\\0&1\end{smallmatrix}\right]$, $\mathbf b=(1,2,3)$. (No exact solution: rows 2 and 3 force $x_1=2$, $x_2=3$, but row 1 needs their sum to be 1.)

1.
$A^TA=\left[\begin{smallmatrix}2&1\\1&2\end{smallmatrix}\right]$ and $A^T\mathbf b=(3,4)$.
2.
Solve $\left[\begin{smallmatrix}2&1\\1&2\end{smallmatrix}\right]\hat{\mathbf x}=\left[\begin{smallmatrix}3\\4\end{smallmatrix}\right]$: $\hat{\mathbf x}=(2/3,\ 5/3)$.
3.
Closest point: $\hat{\mathbf b}=A\hat{\mathbf x}=(7/3,\ 2/3,\ 5/3)$.
4.
Error: $\|\mathbf b-\hat{\mathbf b}\|=\|(-4/3,\ 4/3,\ 4/3)\|=4/\sqrt3$.

Shortcuts and special cases:

  • Independent columns: exactly one answer, $\hat{\mathbf x}=(A^TA)^{-1}A^T\mathbf b$ (Thm 14).
  • Dependent columns: the normal equations have a free variable, so infinitely many $\hat{\mathbf x}$, all reaching the same $\hat{\mathbf b}$.
  • Orthogonal columns: each weight is $\frac{\mathbf b\cdot\mathbf a_j}{\mathbf a_j\cdot\mathbf a_j}$, the formula from 6.2.
  • Have $A=QR$: solve $R\hat{\mathbf x}=Q^T\mathbf b$ from the bottom up (Thm 15).
  • Error 0: $\mathbf b$ was in $\operatorname{Col}A$, so $\hat{\mathbf x}$ is an exact solution.

Don't mix these up

$\hat{\mathbf x}$ is a list of weights. $\hat{\mathbf b}=A\hat{\mathbf x}$ is the closest point. True/false questions like to swap them.

Try it: $x=1$, $x=2$, $x=6$

$A=(1,1,1)$ as a column, $\mathbf b=(1,2,6)$. $A^TA=3$, $A^T\mathbf b=9$, so $\hat x=3$, the average. Error: $\|(-2,-1,3)\|=\sqrt{14}$.
